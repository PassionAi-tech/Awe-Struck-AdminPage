# Awe-Struck Admin

A lightweight, responsive admin dashboard for planning and tracking the Awe-Struck women's Western and Indo-Western clothing store.

## Features
- Editable startup budget and category allocations
- Expense ledger
- Inventory tracker for clothing, sizes, colours, stock and pricing
- Supplier directory
- Sales log and simple profit estimates
- Task checklist
- Browser-local saving with export/import JSON backup

## Run locally
Open `index.html` in a modern browser. No build tools or dependencies are required.

## Data and privacy
This starter stores dashboard data in the current browser using localStorage. It does not sync across devices and is not an authentication system. Do not enter sensitive financial or customer information into a publicly accessible deployment. Add authentication and a database before using it with multiple family members.

## Deployment
Can be hosted as a static site (for example, GitHub Pages) after enabling Pages in repository settings.
